When you open the JoSAA opening and closing rank data, you will see the same branch listed several times with codes such as HS, OS and AI. These are quotas, and understanding them can change your options a lot. This guide explains what they mean.

## The three quotas you will see most

| Code | Name | Meaning |
| --- | --- | --- |
| HS | Home State | Seats reserved for candidates whose state of eligibility is the state where the institute is located. |
| OS | Other State | Seats open to candidates from every other state. |
| AI | All India | Seats open to all candidates, with no state-based division. |

A few institutes in particular states also use special codes, such as for Goa, Jammu and Kashmir, Ladakh and Andhra Pradesh. The information bulletin lists them.

## Which institutes use which quota

- **NITs** divide seats between Home State and Other State, with roughly half of the seats going to each. A candidate competes only within one group.
- **IIITs** mostly use the All India quota, though a few institutes keep a share for their home state.
- **GFTIs** differ from institute to institute. Some use All India, others divide seats between Home State and Other State.
- **IITs** admit on JEE Advanced rank and use the All India quota.

Check the current bulletin for the exact split at each institute, because it can change.

## Who is a home state candidate?

For NITs, your home state is your state of eligibility. In general this is the state in which you passed your Class 12 (or equivalent) examination. It is not decided by where you live now, where your parents are from, or where you took JEE Main. The exact definition, and the special cases for candidates who studied outside their state or in more than one state, are given in the information bulletin each year. Read that section carefully before you fill choices.

## Why quota changes your options

Home State and Other State seats are two separate pools, and each pool has its own closing rank. At an NIT, the Home State pool has fewer candidates in it, because only students from that state compete. This usually means the closing ranks are more relaxed for Home State candidates.

An example with imaginary numbers: if an NIT’s computer science branch closes at rank 3,000 in the Other State pool, it could close at a rank several times higher in the Home State pool. A candidate from that state with rank 8,000 could get a seat there, while a candidate from another state with the same rank could not.

You can use this in two ways.

1. **Look at Home State seats first.** If you are eligible, the NIT in your own state often gives you a better branch than the same NIT does for outsiders.
2. **Do not ignore Other State seats.** You still compete for Other State seats at NITs in every other state, so those belong on your list too.

## What it means for your list

- For the NIT in your home state, you will see Home State seats. For every other NIT, Other State seats apply to you.
- For IIITs and GFTIs, check which quota each uses before comparing ranks.
- Compare like with like. A Home State closing rank for one institute is not comparable with an Other State closing rank for another.

## Common questions

**Can I use Home State quota in more than one state?** No. You have one state of eligibility.

**Do I lose Other State options if I use my Home State?** No. You can be considered for both groups in the same list, and the system allots the best choice available.

**What if I studied Class 12 in a different state from where I live?** Your state of eligibility is based on the rules in the bulletin. Read the definition for your situation or ask the helpline on the official website.
